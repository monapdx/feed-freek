# Changelog

## Design preview — October 2026

- Refined neon layout with more space for article previews.
- Subscription drawer on smaller screens and separate phone reading view.
- Counts for Everything, Unread, and Saved; clearer empty states.
- Search and sorting controls with received/publication date choices.
- Keep selected article previews visible after read-state changes.
- Prevent stale search responses from replacing newer results.
- Clarify bulk mark-read scope before changing reading history.
- Show actual new-story counts after refreshing.
- Validate OPML files before importing and show import progress.
- Split interface into HTML, CSS, and JavaScript for easier customization.
- Fix Windows launcher fallback; add custom-port and no-browser options.
- Include setup, privacy, data backup, publishing, and development documentation.

This is a first design pass for review. Automated Python regression checks and JavaScript syntax checks passed. Desktop and mobile layouts still need visual confirmation in a browser before release.
